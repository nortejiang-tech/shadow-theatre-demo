# 影子剧场：互动式日食与月食科普

一个面向 7–9 岁儿童的单文件 Three.js 互动作品。孩子可以拖动月球距离、改变观察点、观察本影与半影，并用可交互的三维场景理解日食、月食与轨道倾角。

## 运行

直接在现代浏览器打开 [`影子剧场.html`](影子剧场.html)。页面从 CDN 加载 Three.js，因此首次运行需要网络连接。

也可以在仓库根目录启动一个本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。

## 科学边界

- 为了便于观察，三维场景会放大天体与阴影；界面会说明这种视觉夸张。
- 角直径、影锥几何、全食/环食临界和天空亮度的教学关键关系按模型计算，而非按视觉效果猜测。
- [`03-数值验证脚本.py`](03-数值验证脚本.py) 提供独立的数值自检。
